A program that forecasts GTA VI's launch-day Twitch concurrent viewers hour by hour (hours 2–24) as five quantiles per hour, from the comparables and history in each case file.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
